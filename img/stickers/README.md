# Стикеры для пробы «буквы-стикеры» (`hero-sticker.html`)

Картинки — Microsoft Fluent Emoji, стиль 3D (https://github.com/microsoft/fluentui-emoji), лицензия MIT, © Microsoft Corporation.
Исходники 256×256 PNG уменьшены до 200×200 и пересохранены в WebP (качество 82), 20 штук, всего около 100 КБ. Пар и флага Испании в Fluent Emoji нет, они есть только в варианте с системными эмодзи.

Новый стикер: взять `assets/<Название>/3D/<название>_3d.png` из репозитория Fluent Emoji, уменьшить до 200 px, сохранить сюда как `<название-через-дефис>.webp` (у людей – `assets/<Название>/Default/3D/<название>_3d_default.png`) и добавить строку в список `ALL` в `hero-sticker.js`.
