# Формат исходника статьи (source/stati/<slug>.md)

Из этих файлов скрипт `source/build_stati.py` собирает страницы `stati/<slug>.html` и список на `stati.html`.

```
---
title: Интервью в полиции Испании: как проходит и как подготовиться
short: Интервью в полиции          # короткое название для карточек (до ~40 знаков)
cat: Интервью                      # одна рубрика: Основы | Подача | Кейс | Интервью | До отъезда | Документы | Жизнь в Испании
img: stati/intervyu.webp           # файл из img/ (обложки – img/stati/<slug>.webp)
pos: 50% 20%                       # необязательно: точка кадрирования обложки (CSS object-position), если голову режет
lead: Интервью — главный этап... # 1–2 предложения, до 260 знаков
order: 8                           # порядок в списке (меньше — выше)
source: Интервью | https://asiloinspain.notion.site/...   # статья базы знаний, по которой написано (можно несколько через ;)
---
:::short
2–3 предложения: главное из статьи.
:::

## Подзаголовок

Абзацы, списки (- пункт, 1. пункт), **жирный**, [ссылки](https://...).

:::

Ответ.
```

- `:::kb` — тёмная плашка «Полная версия в базе знаний → Открыть в боте». Ставить один раз, в середине статьи.
- Раздел «Вопросы по теме» — всегда последний, 2–4 вопроса, превращается в аккордеон.
- Время чтения считается само.
